# skill-map (Skill-Landkarte) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (Native, recommended) or superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `skill-map build|diff|mark-published|check|fingerprint` keeps the private skill map page current from local files, with a quiet SessionStart reminder.

**Architecture:** A stdlib-only Python package under `ai/skill-map/src/skill_map/`, started by a bash launcher. One discovery module produces `Entry`/`Group`/`Place` objects for both `build` and `check`; `build` adds usage, texts and the page; `check` uses discovery plus the per-entry text hashes only.

**Tech Stack:** Python 3.12+ stdlib (`json`, `tomllib`, `hashlib`, `pathlib`, `re`, `argparse`), pytest, bash launcher, a static HTML page with inline JS.

**Spec:** `docs/superpowers/specs/2026-10-18-skill-map-design.md` (binding; its section "Revision 2026-10-18" overrides older parts).

## Global Constraints

- Python 3.12+, standard library only; no YAML library; launcher passes `bash -n` and `shellcheck`, uses `python3` from `PATH`, resolves its real path (`readlink -f`).
- Writes only under `${XDG_STATE_HOME:-~/.local/state}/skill-map/` (`build/`, `published/`, `published.prev/`); no network; never calls `claude`.
- Config `${XDG_CONFIG_HOME:-~/.config}/skill-map/skill-map.conf` (TOML), every key optional; narrative default `~/.config/skill-map/erzaehlung.html`.
- `$CLAUDE_HOME = ${CLAUDE_CONFIG_DIR:-$HOME/.claude}`.
- CLI, help, README English; page and hook lines German.
- Exit codes: 0 done; 1 runtime error naming the path; 2 usage/config error; `check` always 0.
- Texts are never altered: read bytes, decode strict UTF-8, else withhold. Paths: `$HOME`→`~`, UUID (pair) → `<konto>` with the pattern `[0-9a-f]{8}-[0-9a-f-]{27}(_[0-9a-f]{8}-[0-9a-f-]{27})?`.
- Zero config works (Claude Code's own places + usage); every personal source is optional config. Public docs use neutral scenarios.
- Nothing personal in the repository: fixtures use made-up names; the pre-commit private pattern check must pass.
- Explain-then-run: `build`, `diff`, `mark-published` print each read source / written file with a reason to stderr; `check` is silent unless reporting.

## Review Focus

1. A plugin `description` containing HTML (`<img onerror=…>`) → shown as text on the page, never markup. → Task 6 template hygiene test (only the narrative function uses `innerHTML`) plus a fixture description with markup checked in the manual page run.
2. Huge session logs → `build` streams line by line and only JSON-parses lines with the substrings; never loads a file whole. → Task 4 test with a 50 000-line fixture log under a time bound.
3. `check` run in a session where `installed_plugins.json` is mid-write (truncated JSON) → one "Prüfung fehlgeschlagen" line, exit 0. → Task 7.
4. A `[[projects]]` path that does not exist → no message, no entries (missing places are normal). → Task 3.
5. Two plugins whose agents share a name across prefixes, and a personal command shadowing a project command → distinct keys, no overwritten entry. → Task 3.

## Core interfaces (all tasks)

```python
# paths.py
def claude_home() -> Path; def state_dir() -> Path; def config_dir() -> Path
def tilde(path: Path | str) -> str            # $HOME -> ~, UUID (pair) -> <konto>
UUID_RE: re.Pattern

# config.py
@dataclass class Config: vault: Path; projects: list[Project]; tools: list[str]; builtins: dict[str, str]
    withhold_text: dict[str, str | None]; hide: list[str]; areas: dict[str, str]; source_roots: list[Path]
    synced_skill_prefix: str = "anthropic-skills"; narrative: Path; artifact_url: str | None; title: str = "Skill-Landkarte"
    # vault: Path | None (no default)
def load_config(path: Path | None = None) -> Config      # ConfigError on invalid TOML / wrong type

# frontmatter.py
def front_matter(data: bytes, limit: int = 4096) -> dict[str, str | list[str]]   # first --- block only
def kios_source(data: bytes) -> str | None                                       # first 2000 bytes

# discovery.py
@dataclass class Entry: key; name; call; kind; group; place; desc; path: Path | None; runbook; source_note;
    flags: set[str]; version: str = ""            # usage/text fields are added by build
@dataclass class Group: id; title; place; origin: dict | None; counts: dict[str, int]
@dataclass class Place: id; title; path; scope; color
@dataclass class World: places: list[Place]; groups: list[Group]; entries: dict[str, Entry]; notes: list[str]
def discover(cfg: Config, read_texts: bool = False) -> World    # check uses read_texts=False

# usage.py
def count_usage(world: World, logs: Path) -> UsageResult       # counts[key] = (n, last date), unmatched, since, sessions, skipped

# texts.py
def text_status(entry: Entry, cfg: Config) -> tuple[str, str | None, str | None]  # ("shown"|"withheld"|"none", text, reason); sha set separately

# build.py
def fingerprint(world: World) -> tuple[str, list[list[str]]]   # "sha256:<hex>", sorted set
def build(cfg: Config, out: Path, log: Callable[[str], None]) -> Path
```
